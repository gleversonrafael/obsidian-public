# Comparação visual geral

Esta é uma das partes que eu colocaria diretamente no manual:

|Interface|Formato físico|Sinal|Áudio?|Finalidade principal|Aplicações comuns|
|---|---|---|---|---|---|
|**HDMI**|Pequeno, achatado/trapezoidal|**Digital**|**Sim**|Áudio + vídeo|TVs, monitores, consoles, projetores|
|**DisplayPort**|Retangular com canto chanfrado|**Digital**|**Sim**|Áudio + vídeo|PCs, placas de vídeo, monitores|
|**VGA**|D-sub, 15 pinos|**Analógico**|Não|Vídeo|PCs/projetores antigos|
|**DVI**|Grande, vários pinos|Digital/analógico, conforme variante|Principalmente não|Vídeo|PCs e monitores|
